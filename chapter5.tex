\section{Monitoring the system}
In order to monitor the system and get statistics about usage indices of each layer such as throughtput and latency it has been user the library \textit{dropwizard-metrics} \footnote{http://dropwizard.github.io/metrics} (formerly \textit{codahale metrics}). This library allows to define different type of metrics for couting the ratio of a certain event or the execution time of a function- Each metric refers to a \textit{MetricRegistry} object which accumulates all the received data and publish them using one or more \textit{Reporter}. Example of supported reporter are \textit{CSVReporter}, \textit{HTTPReporter} and \textit{GraphiteReporter}. For our purposes it has been used a \textit{CSVReporter} which append the report for a configurable timewindow to  CSV file.
